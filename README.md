# 视觉回归基线审批与差异定位平台

基于 Vue 3 的本地可运行前端工程，用于管理截图回归运行、差异定位、忽略规则和基线审批。数据由 Axios 模拟适配器提供，并持久化到浏览器 `localStorage`。

## 技术栈

- Vue 3 + TypeScript + Vite
- Arco Design Vue
- Pinia
- Vue Router
- TanStack Query for Vue
- Axios

## 启动

```bash
npm install
npm run dev
```

默认开发地址为 `http://localhost:18471`。

## 构建

```bash
npm run build
npm run preview
```

## 工作区

- 运行概览：发布阻断项、差异趋势和最近运行
- 回归运行：按项目、页面、设备、主题、构建和状态筛选，合并重复运行
- 差异定位：基线/当前图并排、区域缩放、严重级筛选、区域忽略和审批
- 审批队列：批量合并、风险排序和审批入口
- 历史基线：版本、批准人、原因、关联运行和启用状态
- 忽略规则：动态区域选择器、作用范围、最大色差和启用控制
- 结果导出：导出包含运行、差异和审批证据的 CSV

浏览器首次打开时会自动写入示例数据。审批或规则调整会写入 `visual-regression-platform-v1` 对应的本地存储键。

## 判定链（运行 → 规则版本 → 差异区域 → 基线证据）

所有页面的差异率、差异区域和审批数字都来自同一判定链 `src/utils/decisionChain.ts#judgeRun`，列表、详情、导出共用其结果：

- **规则版本化**：每次新建、编辑（作用域/最大色差）、启停或删除规则都会生成不可变快照 `RuleSnapshot`（v1、v2…）。
- **运行锁定依据**：运行采集时锁定当时规则版本；旧运行缺少记录时，按采集时间回填当时有效规则，无法判断的进入「待核对」(`needs-check`)，由人工在详情页回填。
- **打开即记录版本**：审批页/批量审批打开时记录规则版本，提交带该版本；两人同时提交同一运行时，先写入的结论生效，落后页面的取值保留为「冲突草稿」，不覆盖先生效结论。
- **规则改动失效重算**：作用域或色差一改动，判定结果实际受影响的未审批运行立即置为「重算中」(`stale`) 并按新版本重算；重算完成前禁止审批。已审批/驳回运行及其基线保留生成时的冻结证据（规则版本、差异率、区域口径），不随规则后改变化。
- **可恢复审批批次**：批量审批以幂等批次 ID 提交；写入中途失败时保留最近完整批次和已完成项，恢复时只补未完成项。同一运行只允许一条基线，重复提交（含批次重放）按幂等处理，不会多出基线。
- **状态**：`pending` 待审批 / `stale` 重算中 / `needs-check` 待核对 / `approved` 已批准 / `rejected` 已驳回 / `merged` 已合并。

旧的 v1 本地存档在首次读取时自动迁移到 `schemaVersion: 2`。

## 判定链验证

```bash
npm run verify           # 判定链主流程 + v1 存档迁移
npm run verify:chain     # 版本锁定/失效重算/并发冲突/批次恢复/幂等基线
npm run verify:migration # 旧运行规则回填、待核对、已审批证据冻结
```

验证脚本位于 `scripts/`，通过 mock 适配器直接驱动判定链，无需启动浏览器。
